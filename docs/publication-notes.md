# 공개용 저장소 안내

학교 캡스톤 팀 프로젝트의 개인 포트폴리오용 사본입니다. 원본 팀 저장소는 별도로 보관합니다.

- 원래 프로젝트 기간은 2026.03~2026.05입니다. 공개용 정리는 2026년 10월에 진행했습니다.
- 기존 코드와 UI 리소스, 작성자 이름·커밋 날짜·메시지 및 브랜치 병합 이력을 보존했습니다.
- 과거 서버 IP와 배포 주소는 이력에서도 로컬·예시 주소로 바꿨습니다.
- 커밋 작성자의 개인 이메일은 GitHub 비공개용 주소로 치환했습니다. 커밋 ID와 기존 서명 인증은 원본과 다릅니다.
- 원본 GitHub PR·이슈·댓글은 가져오지 않았습니다.
- API 주소는 `REACT_APP_API_BASE_URL` 환경변수로 분리했습니다.

## 역할과 기록의 범위

README의 역할 설명은 당시 보고서에 기재한 내용과 본인의 설명을 기준으로 정리했습니다. Git 커밋 작성자만으로 단독 설계·구현 여부를 확정하지 않습니다. 팀원이 구현한 UI·지도 최적화·백엔드 기능도 포함된 공동 결과물입니다.

`src/assets`의 기존 이미지는 화면 구성용 리소스입니다. 실제 서비스 실행 결과를 증명하는 스크린샷으로 사용하지 않습니다.

## 확인한 항목

공개용 정리 당시 비밀정보 검사와 프론트엔드 프로덕션 빌드를 통과했습니다. 현재 운영 백엔드와의 통합 실행 및 성능 수치는 재검증하지 않았습니다.
